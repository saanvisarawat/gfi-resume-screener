# AI Use Log

I used an AI assistant throughout this project as a pair-programmer to accelerate boilerplate generation. My role as the engineer was to architect the pipeline, design the scoring mathematics and taxonomy, rigorously test everything against all 47 resumes, debug edge cases, and take total ownership of the final logic.

| Pipeline Stage | What the AI did | What I did |
|---|---|---|
| **Data audit** | Wrote the first scripts to dump and inspect the resumes | Architected the audit criteria, read the resumes and audit output, and manually discovered the empty file, garbled text, truncated summary, stray "null", and missing ISO numbers (see `docs/DATA_AUDIT.md`, `docs/CLEANING.md`) |
| **Extraction** | Drafted the initial syntax for the rule-based extractor, section splitter, date parser, and skill matcher based on my specifications | Validated and hardened it against all 47 resumes, catching and rewriting critical logic bugs: wrong experience months, education dates falsely counted as work, a resume ID matching the keyword "ui", and "Design Thinking" in an MBA counting as UI/UX |
| **LLM extraction (first attempt)** | Wrote a Gemini extraction call to try to fill education and projects | Analyzed the API telemetry, diagnosed why every call failed on the dataset, and made the architectural decision to abandon LLM extraction entirely in favor of a robust, deterministic rule-based pipeline |
| **Scoring** | Proposed starting component weights based on prompt guidelines | Defined the core scoring strategy, tuned the component weights against both JDs, and established the precise classification thresholds (LCA 45, UI/UX 35, 12-point gap) by empirically analyzing the score distribution of the 47 resumes |
| **Web app** | Drafted the initial Next.js interface components and upload route based on my UI layout design | Directed the interface design, built the state management and filtering logic, and thoroughly tested it in the browser across docx, pdf, txt, corrupt, oversized, and scanned files before deploying |
| **Validation** | Scaffolded the automated test suite and headline cross-check script structure | Designed the 413 test assertions, hand-read 15 resumes to conduct manual human validation, and verified the system's accuracy against real hiring decisions (see METHODOLOGY section 7) |
